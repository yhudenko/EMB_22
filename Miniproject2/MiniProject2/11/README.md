# Світлофор на ESP-IDF

Реалізував навчальний світлофор для ESP32-S3-N16R8 із відліком секунд
на семисегментному індикаторі BLS-1106BS.

| Стан | Тривалість | Відлік |
|---|---|---|
| Зелений | 9 с | 9 → … → 1 |
| Зелений миготливий | 3 с | 3 → 2 → 1 |
| Жовтий | 3 с | 3 → 2 → 1 |
| Червоний | 9 с | 9 → … → 1 |
| Червоний + жовтий | 2 с | 2 → 1 |

Цикл починається із зеленого й повторюється. Миготіння: 500 мс увімкнено,
500 мс вимкнено. Індикатор показує залишок часу поточного стану й не миготить.
Тривалості обрані для навчального прикладу, задаються в `main/timing.hpp`.

Підключення: A/B/C/D/E/F/G → GPIO4/5/6/7/15/16/17 через резистори ~330 Ω.
COM (контакти 3, 8) → 3.3 V, DP не підключений; сегменти active LOW.
Червоний/жовтий/зелений LED → GPIO8/9/10 через резистори ~330 Ω,
катоди → GND; LED active HIGH. GPIO задані в `main/config.hpp`.

Використав `enum class`, `static constexpr` та superloop з `esp_timer_get_time()`.
Стан і відлік обчислюються від спільного таймера. Без Arduino та динамічної пам’яті
в коді застосунку.

З кореня репозиторію:

```sh
get_idf
cd examples/traffic_light
idf.py -p /dev/cu.usbmodem2101 build flash monitor
```

Порт може змінюватися після перепідключення плати. У моніторі видно переходи станів.
Вихід із монітора: `Ctrl+]`.

Перевірка логіки на комп’ютері з директорії мініпроєкту:

```sh
c++ -std=c++17 -Wall -Wextra -Werror -I main tests/traffic_cycle_test.cpp -o /tmp/traffic_cycle_test
/tmp/traffic_cycle_test
```
